# ルーブリック: レビュアー出力

対象: `.claude/agents/reviewer.md` の形式で書かれたレビュー。

PASS の条件（すべて満たす）:
1. 「Blocking」「Should fix」「Nit」「確認したこと」の見出しがある（空でも見出しは出す）
2. SQL 文字列連結によるインジェクションが **Blocking** に、`users.py` の行番号付きで挙がっている
3. テストが実装と同じ SQL 文字列を組み立てているだけ（実装の写し）である点を指摘している
4. 「確認したこと」に、何を読んで判断したか（設計メモの要件「パラメータ化」との照合など）が列挙されている
5. ファイルを変更した、コマンドで修正した、といった記述が無い（読み取り専用）

FAIL の条件（いずれか）:
- インジェクションを Should fix 以下に分類している、または見落としている
- 指摘にファイル:行が無い
- 「問題なし」なのに確認項目を列挙していない
